Claude Code skills · scrollmark/social-skills

Even AI needs social skills.

Seven installable skills that teach Claude the cultural literacy of the feed — reading tone, dissecting hooks, timing trends, and speaking each platform's dialect. Deep coverage of Instagram, TikTok, and YouTube; X and LinkedIn too.

terminal · via skills.sh 
npx skills add scrollmark/social-skills                  # all seven
npx skills add scrollmark/social-skills -s hook-anatomy  # just one
terminal · symlinks into ~/.claude/skills 
git clone https://github.com/scrollmark/social-skills.git
cd social-skills && ./install.sh

The npx route uses the skills.sh CLI — the open agent-skills ecosystem — and works with Claude Code and other supported agents. Want just one skill? Every card below has its own one-liner.

The full deck

Seven skills, one worldview.

Each one is a compact playbook — patterns and judgment calls, not API wrappers. They pair well with the SocialGPT MCP server, which brings your real numbers into the conversation.

Interpretation

read-the-room

Reads tone, sarcasm, and subtext the way a native does: the four registers (sincere, ironic, performative, parasocial), emoji as grammar, and the comment-section signals most models miss.

Reach for itinterpreting comments, captions, replies, or DMs 
npx skills add scrollmark/social-skills -s read-the-room

Craft

hook-anatomy

The first 1–3 seconds, dissected: six structural hook patterns (curiosity gap, pattern interrupt, identity call-out, and more) and what separates a hook that holds from one that summarizes.

Reach for itanalyzing, scoring, or generating hooks 
npx skills add scrollmark/social-skills -s hook-anatomy

Timing

trend-radar

Maps any trend onto its lifecycle — emergence, growth, peak, saturation, ironic revival — and calls whether the window is still open for you, or only for the parody.

Reach for itdeciding if (and when) a trend is worth riding 
npx skills add scrollmark/social-skills -s trend-radar

Strategy

platform-fluency

How discovery actually works, platform by platform: content-graph TikTok vs follower-graph Instagram vs search-driven YouTube — plus formats, content lifespans, and what each audience came for.

Reach for itplatform conventions, algorithms, audience behavior 
npx skills add scrollmark/social-skills -s platform-fluency

Analysis

content-autopsy

Post-mortems with statistical humility: reads metrics in layers (reach → engagement → saves and shares), separates signal from algorithmic lottery, and insists on patterns over one-off virality.

Reach for itfiguring out why a post took off — or didn't 
npx skills add scrollmark/social-skills -s content-autopsy

Voice

voice-matching

Decomposes a creator's voice into learnable parts — vocabulary, sentence rhythm, opening moves, humor style, CTA habits — so drafts sound like them on their best day, not like an AI doing an impression.

Reach for itwriting as a creator, or auditing consistency 
npx skills add scrollmark/social-skills -s voice-matching

Distribution

repurpose-engine

Adaptation, not cross-posting: keeps the core message and voice, re-cuts format, hook, and framing for each platform. A YouTube essay, a TikTok clip, and a LinkedIn post are three different jobs.

Reach for ittaking one piece of content everywhere it can go 
npx skills add scrollmark/social-skills -s repurpose-engine
