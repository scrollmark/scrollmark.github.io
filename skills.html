Claude Code skills · scrollmark/social-skills

Even AI needs social skills.

Sixteen installable skills: the cultural literacy of the feed — reading tone, dissecting hooks, timing trends, speaking each platform's dialect — plus the craft of making one. Deep coverage of Instagram, TikTok, and YouTube; X and LinkedIn too. Eight of the sixteen need nothing installed; the video engine now lives in the same repo, one pip install away — what each layer gives you.

terminal · via skills.sh 
npx skills add scrollmark/social-skills                  # all 16
npx skills add scrollmark/social-skills -s hook-anatomy  # just one

# Needs Node 22.20+. No Node? Same result without it:
#   mkdir -p ~/social-skills
#   curl -Ls https://github.com/scrollmark/social-skills/archive/refs/heads/master.tar.gz \
#     | tar xz --strip-components=1 -C ~/social-skills
#   ~/social-skills/install.sh
#
# Keep that directory: install.sh symlinks into it, so extracting to /tmp
# loses all 16 skills at the next purge — at once, and with no error.
terminal · symlinks into ~/.claude/skills 
git clone https://github.com/scrollmark/social-skills.git
cd social-skills && ./install.sh

The npx route uses the skills.sh CLI — the open agent-skills ecosystem — and works with Claude Code and other supported agents. Want just one skill? Every card below has its own one-liner. The video skills add an optional second step — pip install from the repo — which the next section lays out.

Before the essay

What do I actually have to install?

Eight of the sixteen need nothing but the skill itself. The rest reach for the engine, and four of them carry scripts that ship inside the skill and run with no install of their own. The long version is below; this is the short one.

Read this before you install

One repo. Four layers.

There used to be a wall here: the prose lived in this repo, and the Python and Remotion toolchain that composites, generates, tracks and renders lived somewhere you could not reach. That wall is gone. The engine moved in — it is src/video_studio/ in the same public repo, and installs from it directly as video-studio-engine. What is left is not a boundary but a ladder: prose you can read anywhere, skills that carry their own programs, skills that want one pip install, and exactly one thing still genuinely outside.

8 skills

Layer one · prose

Nothing to install.

The seven social-media skills are pure judgement — tone, hooks, trend timing, platform dialect, post-mortems, voice. No external tools, no accounts, no keys. So is agent-interview, which has nothing video-specific in it. These are the same whichever way you install them.

read-the-room hook-anatomy trend-radar platform-fluency content-autopsy voice-matching repurpose-engine agent-interview
4 skills

Layer two · prose + a bundled script

Executable the moment you install the skill.

Six programs are pure standard library and take their input on the command line, so they ship inside the skill folder that uses them and travel with npx skills add like any other file: doctor.py (what is reachable right now), measure.py (durations and a track's energy structure), normalize_audio.py (loudness after a render), poster.py (thumbnail shortlist and contact sheet), qc_render.py (the render checked against the plan it was built from) and prekey.py (key a generated clip to alpha). Two of them are carried by two skills each — eight copies across four skills — because a skill may never reach outside its own folder.

They want ffmpeg and ffprobe on your PATH. That is the one thing the repo cannot ship for you.

studio-setup audio-acquisition media-acquisition video-production
34 programs

Layer three · one pip install

The engine, from the repo.

The other thirty-four programs either carry third-party dependencies or read a project's state — a props document, a composer directory, a styles tree — which makes them unfit to sit in a skill folder as a lone file. They are built from src/video_studio/ and run as video-studio <command>. The base install is deliberately thin; the heavy dependencies are opt-in extras, so you install the half you actually use.

terminal · optional, video skills only 
uv tool install --python 3.12 --refresh 'video-studio-engine[standard] @ https://github.com/scrollmark/social-skills/archive/refs/heads/master.tar.gz'

# Needs no git, no Xcode tools and no system Python — uv brings its own.
# Get uv first:  curl -LsSf https://astral.sh/uv/install.sh | sh
#                source "$HOME/.local/bin/env"    # or open a new terminal
#
# --python 3.12 is pinned: on 3.13 the [audio] extra installs cleanly and
# silently has no voice. --refresh because GitHub's tarball is cached forever.

# Or one extra at a time — same URL, different bracket:
#   [sourcing]  + source_clips (yt-dlp)
#   [audio]     + tts_kokoro, gen_music, duck_music
#   [captions]  + gen_captions (local whisper word timings)
#   [generate]  + gen_veo, gen_boil
#   [vision]    + composite_subject, track_pointing  (needs mediapipe)
#   [export]    + export_edit (OpenTimelineIO)
#   [qc]        + qc_analyze — the render checked against its plan, decoded
#
# The four model-backed QC checks stay opt-in, one extra each:
#   [qc-ocr]  captions and text layout    [qc-yolo]  planned subjects on screen
#   [qc-face] lip sync                    [qc-clip]  scene footage vs its prompt

It installs from the repo, not from PyPI — the name video-studio-engine is not published there, so a bare pip install video-studio-engine does not get you this. The URL is the install.

It is independent of the skills and installed separately — npx skills add never touches it. It is also genuinely optional, and being honest about that matters more than making the repo look complete: a skill whose work needs the package is not self-contained for a user who skips it. The cards below say exactly what skipping it costs.

licences, not code

Layer four · yours to licence

A Remotion licence, and the keys.

The Remotion composer ships in this repo now — composer/, React driven entirely by the props document the engine writes. What is still not ours to ship is Remotion itself: the project declares it as a dependency and vendors none of it, because Remotion requires a paid Company Licence above three people and for hosted or automated rendering. The code is here; that licence stays between you and them. It is Node, not Python, so npm install in composer/ once, and then npx remotion render turns a storyboard into a file.

ElevenLabs voice has a script now — video-studio tts_eleven — but it bills per character and returns no word timings, so captions for an ElevenLabs read come from gen_captions. The local voice is free and runs offline; reach past it deliberately. The automated quality gate at the last step of a production run used to be an unpublished internal CLI; it is now qc_render.py, bundled, needing no install. It proves a render matches its plan — it cannot tell you the plan was worth rendering, so the looking is still yours.

If you skip the pip install

What you still get.

Layer three is optional. Here is the honest accounting of what each video skill is worth without it.

loses nothing

Unaffected

The whole social half.

All seven social-media skills and agent-interview are untouched by any of this.

studio-setup loses the least of the video skills: doctor.py ships with it, so the status report and the triage work immediately. Only the install plan — video-studio setup and its auto/system/manual classification — needs the package.

audio-acquisition is the best-off of the production skills. It carries measure and normalize_audio, so the measure-don't-trust discipline and the music-costs-6-dB fix are both executable out of the box. Voice, generated music and licence-filtered effects are [audio].

holes in it

Partly executable

Useful, with holes in it.

video-formats still works for eight of its ten formats — those are structure you can follow in any editor. Boil is roughly 40% inoperative without [generate]: its mark vocabulary, shape files and palette workflow are gen_boil, so the interview questions have no answers to pick from. PointerPopups does not work at all as written without [vision] — its entire grammar is the output of a hand-tracking pass.

brand-kit lets you agree a brand with someone and hand-write the files. The preset mechanism that lists, shows, saves and applies one is video-studio styles, so applying a brand becomes manual editing.

media-acquisition keeps prekey. The provider ladder and the landmine list will still tell a human which library to open, but the searching, generating, licence filtering and the five-way check on what came back are [sourcing,generate].

briefings

Package-side

Briefings, not workflows.

subject-compositing is entirely package-side: segmentation, the feathered occlusion seam, the arm punch-through and the gesture timing all need [vision], because MediaPipe and OpenCV cannot be bundled into a skill folder. What survives is the footage brief — what a segmenter needs from a take — and it is worth having before anyone films.

edit-handoff cannot produce a file without [export]; the exporters read the engine's per-project timeline document. What generalises is the judgement: which format each application actually imports, and that no interchange format carries effects.

video-production ships doctor, normalize, poster and qc_render, but it sequences the whole engine — props, preview, preflight — and the Remotion renderer on top. With none of those present there is nothing to sequence. What survives is the shape of a production run: which decision precedes which, and where money enters.

Each of those skills states its own dependency in a ## Requires section near the top of its SKILL.md — that is where the authoritative answer lives. The longer version of this page is in the README.

The full deck

Sixteen skills, three jobs.

Reading social media, producing short-form video, and the working method underneath both. Each one is a compact playbook — patterns and judgment calls, not API wrappers. They pair well with the SocialGPT MCP server, which brings your real numbers into the conversation.

Group one · 7 skills

Understanding social media.

Tone, hooks, trends, platform conventions, creator voice. All seven run standalone — no external tools, no accounts, no keys.

Interpretation

read-the-room

Reads tone, sarcasm, and subtext the way a native does: the four registers (sincere, ironic, performative, parasocial), emoji as grammar, and the comment-section signals most models miss.

Reach for it interpreting comments, captions, replies, or DMs 
npx skills add scrollmark/social-skills -s read-the-room

Craft

hook-anatomy

The first 1–3 seconds, dissected: six structural hook patterns (curiosity gap, pattern interrupt, identity call-out, and more) and what separates a hook that holds from one that summarizes.

Reach for it analyzing, scoring, or generating hooks 
npx skills add scrollmark/social-skills -s hook-anatomy

Timing

trend-radar

Maps any trend onto its lifecycle — emergence, growth, peak, saturation, ironic revival — and calls whether the window is still open for you, or only for the parody.

Reach for it deciding if (and when) a trend is worth riding 
npx skills add scrollmark/social-skills -s trend-radar

Strategy

platform-fluency

How discovery actually works, platform by platform: content-graph TikTok vs follower-graph Instagram vs search-driven YouTube — plus formats, content lifespans, and what each audience came for.

Reach for it platform conventions, algorithms, audience behavior 
npx skills add scrollmark/social-skills -s platform-fluency

Analysis

content-autopsy

Post-mortems with statistical humility: reads metrics in layers (reach → engagement → saves and shares), separates signal from algorithmic lottery, and insists on patterns over one-off virality.

Reach for it figuring out why a post took off — or didn't 
npx skills add scrollmark/social-skills -s content-autopsy

Voice

voice-matching

Decomposes a creator's voice into learnable parts — vocabulary, sentence rhythm, opening moves, humor style, CTA habits — so drafts sound like them on their best day, not like an AI doing an impression.

Reach for it writing as a creator, or auditing consistency 
npx skills add scrollmark/social-skills -s voice-matching

Distribution

repurpose-engine

Adaptation, not cross-posting: keeps the core message and voice, re-cuts format, hook, and framing for each platform. A YouTube essay, a TikTok clip, and a LinkedIn post are three different jobs.

Reach for it taking one piece of content everywhere it can go 
npx skills add scrollmark/social-skills -s repurpose-engine

Group two · 7 skills

Producing video.

Craft skills for making a short-form video, not only planning one. The judgement is prose you can follow anywhere; the execution is a script bundled in the skill, or one install away in the same repo — and since the Remotion composer moved in, that now includes the render itself. See what each layer gives you.

Structure

video-formats

Ten scene grammars, from talking-head to hand-drawn motion graphics — how to pick one for a video, lay out its scenes, and critique the result. Or define a new grammar when none of the ten fits.

Reach for it planning, structuring, or critiquing a short-form video
8 of 10 formats need nothing Boil + PointerPopups: pip install 
npx skills add scrollmark/social-skills -s video-formats

Consistency

brand-kit

Caption styling, card colours and geometry, title treatment, logos, fonts, voice and CTA copy — decided once and written down, instead of re-argued on every video.

Reach for it keeping a run of videos visually consistent
presets need pip install 
npx skills add scrollmark/social-skills -s brand-kit

Sourcing

media-acquisition

Where a shot's footage or stills should come from — public-domain archive, free stock, a paid generator, or a URL the user supplied — and how to check that what came back is actually usable before anything is built on it.

Reach for it deciding where a shot's pictures come from
ships prekey.py pip install [sourcing,generate] 
npx skills add scrollmark/social-skills -s media-acquisition

Sound

audio-acquisition

Narration, music beds and sound effects: choosing a voice, deciding which music source is safe to publish with, timing a cut to a track, and diagnosing a render that came out quiet.

Reach for it a video needs a voice, a bed, or a fix for bad levels
ships measure + normalize voice + music: pip install [audio] 
npx skills add scrollmark/social-skills -s audio-acquisition

Compositing

subject-compositing

A filmed person appearing somewhere they never were — a subject dropped over replacement footage, a drawn prop in front of them, the pair driven across frame, popups pinned to where they point on camera.

Reach for it planning a shot that composites a person into a scene
pip install [vision] 
npx skills add scrollmark/social-skills -s subject-compositing

Handoff

edit-handoff

What happens when a finished cut leaves the pipeline and continues in a human editor: exporting a timeline to Premiere Pro, DaVinci Resolve, Final Cut Pro or CapCut, and knowing what survives the trip and what has to be rebuilt.

Reach for it an editor is picking the cut up from here

Pipeline

video-production

The end-to-end run in order — interview, storyboard, source, preview, render, quality-check — plus the rules that only make sense across a whole production: quote the cost before the first paid call, preview with placeholders before spending, and which step owns a stall.

Reach for it producing a video end to end, or a run has stalled
