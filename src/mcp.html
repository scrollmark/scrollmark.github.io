What you are granting

Read by default. One tool posts.

Connecting runs OAuth 2.1 with PKCE — the server never sees a password and never asks you for an API key. It identifies itself as public-read-v1 and declares six scopes:

analysis:read analysis:read:public analysis:upload content:ingest content:publish content:write

Posting is not something it does quietly

Of the twenty-six tools, exactly one publishes to a platform, and it will not run without an explicit attestation that a human approved that content for that destination. Posting straight to TikTok needs more still: a token minted by a separate call, a privacy level a person picked by hand, and a second attestation that they previewed it. The soft path — a draft that lands in your TikTok inbox for you to finish there — is the default.

Limits, and how to take it back

Publishing is capped at ten calls an hour and analysing a post at thirty, so nothing runs away with your account. Public and competitor analysis needs no connected account at all. Manage or disconnect the accounts you have connected from your SocialGPT account page.
